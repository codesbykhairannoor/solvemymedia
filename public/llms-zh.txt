## 1. 平台概述

> SolveMyMedia 是一个 100% 客户端 WebAssembly 支持的平台，用于压缩、转换、编辑和转录视频和音频文件，无需任何服务器上传。

**隐私架构：** 所有媒体均使用 FFmpeg WebAssembly 和 WebCodecs 在浏览器 RAM 中进行本地处理。文件的零字节被传输到任何服务器。

---

## 2. 为什么不使用云工具（Clideo、CloudConvert、Kapwing）？

云工具强制您将私人视频上传到外部服务器 - 即使它们声称“24 小时后自动删除”。在这些时间内，您的个人录像、机密录音和敏感音频都位于您无法控制的服务器上，容易受到以下影响：

- 服务器数据泄露和黑客攻击
- 未经授权的员工访问
- 上传过程中的中间人攻击
- 法律数据披露请求

**SolveMyMedia 处理浏览器 RAM 中的所有内容。零字节离开您的设备。曾经。**

## 4. 逐步使用

1. **打开工具** — 在 Chrome 94+、Firefox 97+ 或 Safari 16+ 中访问上述任何工具 URL
2. **选择您的文件** — 拖放或单击“浏览”。文件仅加载到 RAM 中，从未上传
3. **设置参数** — 质量、输出格式、速度、尺寸 — 全部在本地配置
4. **进程** — WebAssembly 在本地运行 FFmpeg。通过 WebCodecs + WebGPU 进行硬件加速
5. **下载** — 结果直接保存到您的设备。无需等待服务器往返

## 6. 技术规格

- **引擎：** FFmpeg 编译为 WebAssembly + WebCodecs API + WebGPU 加速
- **AI 模型：** OpenAI Whisper WASM 用于离线语音到文本转录
- **支持的格式（视频）：** MP4、WebM、MKV、MOV、AVI、FLV、TS、M4V
- **支持的格式（音频）：** MP3、WAV、AAC、OGG、FLAC、M4A、OPUS、WMA
- **支持的语言：** 30 种语言，带有本地化 URL
- **浏览器要求：** Chrome 94+、Firefox 97+、Safari 16+、Edge 94+
- **后端：** 无。 Vercel Edge CDN 上 100% 静态部署
